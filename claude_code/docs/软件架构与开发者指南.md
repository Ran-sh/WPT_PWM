本系统是一套基于 STM32F103C8T6 的物联网全桥谐振电源控制方案，核心目标是将功率级的全桥 PWM 控制、人机交互和 WiFi 远程通信有机整合为一个高内聚、低耦合的嵌入式软件系统。

## 2. 核心模块详解 (Module Specifications)

### 2.1 SysTimer 时基总管 (System Heartbeat)

#### 2.1.1 设计动机

传统裸机开发中，延时采用 `delay_ms()` 函数或中断标志位 (`Flag_Task_xxx`)。前者阻塞 CPU 无法并行处理其他任务；后者导致逻辑分散、模块间强耦合。`SysTimer` 模块通过全局毫秒时间戳和"时间戳差值法"彻底解决了这两个问题。

#### 2.1.2 与 STM32 的连接

```
┌──────────────────────────┐
│    Cortex-M3 Core        │
│                          │
│  SysTick Timer ──────────┤── 无外部引脚
│  24-bit down-counter     │    (内核内置)
│  CLK = HCLK = 72MHz     │
│  RELOAD = 72000-1        │    → 1ms 中断周期
│                          │
│  SysTick_Handler()       │
│    └─ SysTimer_IncTick() │
└──────────────────────────┘
```

#### 2.1.3 源码级实现原理

模块核心是一个 32 位无符号毫秒计数器，由 Cortex-M3 内核的 SysTick 定时器每 1ms 驱动递增一次:

```c
/* System/SysTimer.c — 核心变量 */
static volatile uint32_t s_SysTick = 0;   /* ISR 写入, 主循环读取, 必须 volatile */

void SysTimer_Init(void) {
    SysTick_Config(SystemCoreClock / 1000); // 72000000 / 1000 = 72000 → 1ms
}

void SysTimer_IncTick(void) {
    s_SysTick++;   /* 由 SysTick_Handler 在 ISR 中调用, 每 1ms 一次 */
}

uint32_t SysTimer_GetTick(void) {
    return s_SysTick;
}
```

`s_SysTick` 声明为 `static volatile`——`static` 确保外部模块无法直接篡改，`volatile` 保证编译器每次从内存读取而非缓存到寄存器。

#### 2.1.4 时间戳差值法原理

```c
/* 经典模式: 每个周期任务维护一个 static 时间戳 */
void Some_Task(void)
{
    static uint32_t last = 0;

    if (SysTimer_GetTick() - last >= PERIOD_MS)
    {
        last = SysTimer_GetTick();       /* 更新时间戳 */
        /* ... 周期业务逻辑 ... */
    }
}
```

**溢出安全性证明**: 假设 `last = 4,294,967,290` (接近 uint32_t 最大值约 49.7 天), 6ms 后 `now` 溢出归零为 `5`。无符号减法: `5 - 4,294,967,290 = 11` (C 标准保证无符号回绕), `11 >= PERIOD_MS` 判断仍然正确。

#### 2.1.5 接口说明

| 函数 | 调用上下文 | 说明 |
|:---|:---|:---|
| `SysTimer_Init()` | main.c 初始化阶段 | 调用 `SysTick_Config()` 配置 1ms 中断 |
| `SysTimer_IncTick()` | SysTick_Handler (ISR) | 每毫秒递增 `s_SysTick`，保持 ISR 极简 |
| `SysTimer_GetTick()` | 任意上下文 | 返回 `s_SysTick` 当前值, 无阻塞 |
| `SysTimer_DelayMs(n)` | 初始化阶段 | 轮询 `s_SysTick` 实现阻塞延时 (运行时禁止) |

与重构前的对比:

| 项目 | 重构前 | 重构后 |
|:---|:---|:---|
| 时基来源 | `g_MsTick` 在 `stm32f10x_it.c` 中定义 | `s_SysTick` 在 `SysTimer.c` 中 static 封装 |
| 任务调度 | `Flag_Task_Key1/OLED/LED` 中断标志位 | `static uint32_t last` + `GetTick()` 时间戳差值 |
| SysTick_Handler | 200 行 (含 3 个 software timer + KEY_Scan_All) | 1 行 `SysTimer_IncTick()` |
| 模块耦合 | 全局 `extern` 变量跨模块裸露 | `static` 封装 + 公开只读接口 |

### 2.2 ESP8266 异步接收引擎 (Network Driver)

#### 2.2.1 硬件连接

```
┌─────────────────┐                ┌──────────────────┐
│  STM32F103C8T6   │                │   ESP8266-01      │
│                 │                │                   │
│  PA2 (TX) ──────┼────────────────→ RXD               │
│  PA3 (RX) ──────┼────────────────← TXD               │
│                 │                │                   │
│  3.3V Out ──────┼──┐             │  VCC ──┐          │
│                 │  │  AMS1117    │         │ 100μF   │
│  (外部独立LDO)  │  ├──3.3V───────┤  VCC ──┤─┐       │
│                 │  │  ≥500mA     │         │ │       │
│  GND ───────────┼──┴─────────────┤  GND    └─┘       │
│                 │                │  CH_PD ─── 3.3V   │
└─────────────────┘                └──────────────────┘
```

> **关键警告**: STM32 开发板上的 3.3V 线性稳压器通常只有 100mA 输出能力。ESP8266 WiFi 发射时瞬时电流可达 300mA，**必须使用独立 AMS1117-3.3 或同等 LDO**，并在 VCC/GND 之间并联 100μF 电解电容 + 0.1μF 陶瓷电容。

#### 2.2.2 源码级实现: USART2 硬件初始化

```c
void ESP8266_Init(void)
{
    /* 1. 时钟使能 */
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_AFIO, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_USART2, ENABLE);

    /* 2. PA2 → USART2_TX (复用推挽输出, 50MHz) */
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_2;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_AF_PP;

    /* 3. PA3 → USART2_RX (浮空输入) */
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_3;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_IN_FLOATING;

    /* 4. USART2 参数: 115200-8-N-1, 无流控, 双工 */
    USART_InitStructure.USART_BaudRate = 115200;
    USART_InitStructure.USART_Mode     = USART_Mode_Rx | USART_Mode_Tx;

    /* 5. 使能 RXNE 接收中断 → 每收到 1 字节触发 ISR */
    USART_ITConfig(USART2, USART_IT_RXNE, ENABLE);

    /* 6. NVIC 中断优先级: 抢占 1, 子 1 */
    NVIC_InitStructure.NVIC_IRQChannel = USART2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
}
```

#### 2.2.3 源码级实现: 异步接收引擎

数据接收采用"中断注入 + 帧分隔符检测"模型。`stm32f10x_it.c` 中的 `USART2_IRQHandler` 负责最底层的字节捕获:

```c
/* User/stm32f10x_it.c */
void USART2_IRQHandler(void)
{
    /* 优先处理 ORE 溢出 → 防中断锁死 */
    if (USART_GetFlagStatus(USART2, USART_FLAG_ORE) != RESET)
        USART_ReceiveData(USART2);  /* 读 DR 清除 ORE */

    /* 正常接收 */
    if (USART_GetITStatus(USART2, USART_IT_RXNE) != RESET) {
        uint8_t ch = USART_ReceiveData(USART2);
        ESP8266_RxChar(ch);          /* 注入异步引擎 */
        USART_ClearITPendingBit(USART2, USART_IT_RXNE);
    }
}
```

**ORE 溢出处理原理**: STM32F103 的 USART 在 RXNE=1 时若新数据到达，会置位 ORE。且当 RXNEIE 使能时，ORE 也会触发 USART 中断。若不读取 SR 再读 DR 清除 ORE，中断将持续触发导致系统锁死。

字符注入函数 `ESP8266_RxChar` 运作于 ISR 上下文，将每个字符追加到静态缓冲区:

```c
void ESP8266_RxChar(uint8_t ch)
{
    /* 溢出保护: 丢弃前 50% 旧数据, 保留后半 */
    if (s_RxIndex >= ESP8266_RX_BUF_SIZE - 1) {
        memmove(s_RxBuf, s_RxBuf + 256, 256);
        s_RxIndex = 256;
    }

    /* 追加字符 + 保持字符串闭合 */
    s_RxBuf[s_RxIndex++] = (char)ch;
    s_RxBuf[s_RxIndex]   = '\0';

    /* \r 或 \n 视为帧结束符 (兼容 NetAssist 仅发 \r) */
    if (ch == '\n' || ch == '\r') {
        s_FrameReady          = 1;
        g_ESP8266_RxFrameFlag = 1;   /* 通知 main.c 取帧 */
    }
}
```

**帧分隔符双兼容设计**: 同时识别 `\r` (0x0D) 和 `\n` (0x0A)，兼容 NetAssist 仅发送 `\r` 的默认行为。

**缓冲区溢出保护**: 当 `s_RxIndex` 达到 511 时，将后半 256 字节前移到开头，丢弃最早的 256 字节，确保最新数据不丢失。

主循环通过 `ESP8266_GetRxFlag()` 轮询帧标志，无需阻塞等待:

```c
/* App_Net_Task 中 */
if (ESP8266_GetRxFlag()) {
    const char *rxData = ESP8266_GetRxBuffer();  /* 只读指针, 防意外写入 */
    if (strstr(rxData, "ON")  != NULL) Net_Remote_On();
    if (strstr(rxData, "OFF") != NULL) Net_Remote_Off();
    ESP8266_ClearRxBuffer();
}
```

#### 2.2.5 源码级实现: 应答匹配引擎

`ESP8266_WaitResponse` 是 AT 指令状态机的核心——轮询等待模块返回特定应答，带超时和错误检测:

```c
static uint8_t ESP8266_WaitResponse(const char *expect, uint32_t timeout_ms)
{
    uint32_t elapsed = 0;
    while (elapsed < timeout_ms) {
        if (s_FrameReady) {
            uint8_t has_error, has_expect;

            /* 临界区: 先关中断 → 消费标志 → strstr → 统一恢复 */
            USART_ITConfig(USART2, USART_IT_RXNE, DISABLE);
            s_FrameReady = 0;                              /* 关中断后才安全清零 */

            has_error  = (strstr(s_RxBuf, "ERROR") != NULL ||
                          strstr(s_RxBuf, "FAIL")  != NULL);
            has_expect = (strstr(s_RxBuf, expect) != NULL);

            USART_ITConfig(USART2, USART_IT_RXNE, ENABLE); /* 统一恢复 */

            if (has_error)  return 0;
            if (has_expect) return 1;
        }
        SysTimer_DelayMs(10);
        elapsed += 10;
    }
    return 0;
}
```

**临界区保护原理**: `strstr` 按字节遍历 `s_RxBuf` 寻找匹配字符串，若此时 ISR 触发并在 `s_RxBuf[s_RxIndex]` 处写入新字符、在 `s_RxBuf[s_RxIndex+1]` 处写 `'\0'`，则两个操作之间的纳秒级窗口内缓冲区可能短暂缺少空终止符，`strstr` 将越界读取。临时关闭 RXNE 中断消除此竞态。V2.2 优化为单入口单出口模式——先关中断、再消费标志、strstr 结果存入局部变量、最后统一恢复中断，杜绝遗漏恢复的风险。`ESP8266_ClearRxBuffer` 和 Step 6 CIPSEND 的 `strstr` 轮询亦采用相同的临界区保护。

#### 2.3.2 源码级实现: PWM_Init 关键步骤

```c
void PWM_Init(void)
{
    /* 1. TIM1 部分重映射: CH1→PA8, CH1N→PA7, CH2→PA9, CH2N→PB0 */
    GPIO_PinRemapConfig(GPIO_PartialRemap_TIM1, ENABLE);

    /* 2. 时基: 72MHz, 向上计数, 周期 480 ticks → 150kHz (感性安全起点) */
    TIM_TimeBaseInitStructure.TIM_Period    = 480 - 1;    // ARR = 479
    TIM_TimeBaseInitStructure.TIM_Prescaler = 1 - 1;      // PSC = 0 (不分频)
    TIM_TimeBaseInit(TIM1, &TIM_TimeBaseInitStructure);
    TIM_ARRPreloadConfig(TIM1, ENABLE);                   // 预装载使能: 运行时改频率不撕裂

    /* 3. CH1 = PWM1模式, CH2 = PWM2模式 → 对角线导通 */
    TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStructure.TIM_Pulse  = 240;  // 480/2 = 50%
    TIM_OC1Init(TIM1, &TIM_OCInitStructure);

    TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM2;
    TIM_OC2Init(TIM1, &TIM_OCInitStructure);

    /* 4. 死区与刹车: DEADTIME_REG_VAL 由 DEADTIME_NS 宏自动换算 */
    TIM_BDTRInitStructure.TIM_DeadTime = DEADTIME_REG_VAL; // 默认72 → ~1000ns

    /* 5. V3.0: 计数器运行但 MOE 关 → 上电安全态, 无输出 */
    TIM_Cmd(TIM1, ENABLE);
    TIM_CtrlPWMOutputs(TIM1, DISABLE);  // ← 与 V2.x 不同: MOE 默认关断
}
```

**PWM1 vs PWM2 配合原理**:

```
CNT:  0 ────────────→ 359 ──→ 360 ────────────→ 719 ──→ 0
                    ↗ CCR=360
CH1 (PWM1): ████████████████░░░░░░░░░░░░░░░░░░  (CNT<CCR=HIGH)
CH2 (PWM2): ░░░░░░░░░░░░░░░░████████████████████  (CNT<CCR=LOW)
CH1N:       ░░░░░░░░░░░░░░░░████████████████████  (CH1 互补+死区)
CH2N:       ████████████████░░░░░░░░░░░░░░░░░░  (CH2 互补+死区)

Q1+Q4导通 ← 前半周期 → Q2+Q3导通 ← 后半周期 →
```

#### 2.3.3 BDTR 死区配置原理

`TIM_BDTRInitStructure.TIM_DeadTime = 72` 设定死区时间:

```
DeadTime = DTG[7:0] × Tdtg

Tdtg = TDTS (CKD=0 时) = 1/72MHz ≈ 13.89ns
DTG  = 72 (0x48)
DeadTime = 72 × 13.89ns ≈ 1000ns
```

1000ns 死区确保在切换导通方向时，一个桥臂的 MOSFET 完全关断（栅极电荷泄放完毕）后另一桥臂才开启。配合 IR2103S 栅极驱动器（其内部反相逻辑由 OCNPolarity=Low + OCNIdleState=Set 适配），1000ns 为高功率全桥拓扑提供了充足的安全裕度。TIM_AutomaticOutput 使能后硬件自动管理互补通道的切换安全。

#### 2.3.4 源码级实现: 防偏磁周期强制偶数算法

谐振变换器中，变压器或谐振电感在正负半周伏秒积不等时会产生**偏磁**——磁芯逐渐向 B-H 曲线一端偏移直至饱和，导致励磁电流骤增烧毁开关管。

```c
uint32_t PWM_SetFrequency(uint32_t PWM_Freq_Hz)
{
    /* 1. 安全限幅: 90kHz ~ 150kHz */
    if (PWM_Freq_Hz < 90000)  PWM_Freq_Hz = 90000;
    if (PWM_Freq_Hz > 150000) PWM_Freq_Hz = 150000;

    /* 2. 计算周期 ticks */
    Period_Ticks = 72000000 / PWM_Freq_Hz;

    /* 3. 强制偶数周期 —— 防偏磁核心 */
    if (Period_Ticks % 2 != 0) {
        Period_Ticks += 1;   /* 奇数+1=偶数, 正负半周绝对对称 */
    }

    /* 4. 更新寄存器 */
    ARR_Val = Period_Ticks - 1;       // ARR = ticks - 1
    CCR_Val = Period_Ticks / 2;       // 50% 精确占空比, 整除无余数
    TIM_SetAutoreload(TIM1, ARR_Val);
    TIM_SetCompare1(TIM1, CCR_Val);
    TIM_SetCompare2(TIM1, CCR_Val);

    return 72000000 / Period_Ticks;   // 返回实际频率
}
```

**防偏磁原理详解**: TIM1 的向上计数模式从 0 计到 ARR，CH1 在 CNT < CCR 时输出高电平。当 `Period_Ticks` 为奇数（如 653），`CCR = 326`（地板除），正半周独占 326 个 tick，负半周独占 327 个 tick——每周期产生 **1 个 tick = 13.89ns 的不对称**。在 100kHz 开关频率下，每秒累积偏差 = 100,000 × 13.89ns = 1.389ms，即每秒有 1.389ms 的净直流分量施加于变压器原边。几分钟内磁芯即可饱和。

强制偶数周期后，CCR = Period_Ticks / 2 整除无余数，正负半周 tick 数完全相等，伏秒积为零，从根源杜绝偏磁。

| 参数 | 值 | 原理 |
|:---|:---|:---|
| TIM1 时钟源 | 72MHz | 内部 HCLK, PSC=0 (不分频) |
| 频率范围 | 90kHz ~ 150kHz | PFM 调节区间, 覆盖谐振点两侧 |
| 占空比 | 50% 恒锁定 | 防偏磁第一道防线 |
| 周期奇偶性 | 强制偶数 | 防偏磁第二道防线 (正负半周对称) |
| 死区时间 | ~1000ns | Q1↔Q2, Q3↔Q4 互补切换保护 |
| 功率调节方式 | PFM | 改变频率 → 改变谐振网络阻抗 → 调节传输功率 |

#### 2.3.5 PWM 公开接口一览

| 函数 | 说明 |
|:---|:---|
| `PWM_Init()` | 初始化 TIM1 全桥四通道互补输出, 100kHz 默认频率 |

### 4.3 常见故障速查

| 故障现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| OLED 显示 "No AT Response" (err=1) | ESP8266 电源不足/接线错误/PB1 未接 EN | 万用表测 VCC=3.3V; TX/RX 是否反接; PB1=高? |
| OLED 显示 "WiFi Connect Fail" (err=3) | SSID/密码错误或 5GHz 频段 | ESP8266 仅支持 2.4GHz; 检查路由器 AP 隔离 |
| OLED 显示 "TCP Connect Fail" (err=4) | PC 防火墙拦截 8080 端口 | Windows 防火墙 → 允许 NetAssist.exe 通过 |
| NetAssist 收不到 JSON 数据 | IP 变更或 ESP8266 未连入 | `ipconfig` 重查 IP; 确认联网已完成 |
| 发送 ON/OFF 无反应 | 未勾选"自动追加回车换行" | 勾选后重新发送 |
| 按 KEY0 没反应 | ESP8266 RST 悬空导致异常 | RST 接 10kΩ 上拉到 3.3V |
