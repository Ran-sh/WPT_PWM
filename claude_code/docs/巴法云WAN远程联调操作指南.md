# 巴法云远程联调操作指南

> **适用场景**: STM32F103C8T6 + ESP8266-01 WiFi 透传 → 巴法云 TCP 创客云 → 手机/PC 远程控制  
> **目标读者**: 嵌入式测试工程师 / 项目验收人员  
> **预计耗时**: 10 分钟完成全部配置

---

## 一、前置准备

### 1.1 确保硬件连接正确

| 单片机引脚 | ESP8266-01 引脚 | 说明 |
|:---:|:---:|:---|
| PA2 (USART2_TX) | RXD | 单片机发 → 模块收 |
| PA3 (USART2_RX) | TXD | 模块发 → 单片机收 |
| 3.3V | VCC, CH_PD (EN) | **必须 3.3V 供电, 严禁 5V!** |
| GND | GND, GPIO0 | GPIO0 悬空或拉高 = 运行模式 |

> ⚠️ **致命警告**: ESP8266 的 VCC 必须用 **3.3V** 供电。STM32F103 的 5V 直供会烧毁 WiFi 模块。  
> 建议使用独立的 3.3V LDO (如 AMS1117-3.3) 提供 ≥500mA 电流，因为 WiFi 发射瞬时电流可高达 300mA。

### 1.2 确保单片机固件已烧录

固件配置文件位于 `User/App_Net.h`，需要确认以下宏与你的实际环境匹配：

```c
#define WIFI_SSID       "Xsyy"                  // ← 改成你的 WiFi 名
#define WIFI_PASSWORD   "**********"            // ← 改成 WiFi 密码
#define SERVER_IP       "114.116.142.124"       // 巴法云 TCP 公网 IP (无需修改)
#define SERVER_PORT     8344                    // 巴法云 TCP 端口 (无需修改)
#define BEMFA_UID       "382d6976a7f647bb856143e0b32eb9d3"  // ← 替换为你的巴法云私钥
#define BEMFA_TOPIC     "WPT001"                // ← 自定义主题名 (建议保留)
```

> 📌 **注意**: `SERVER_IP` 和 `SERVER_PORT` 已固定为巴法云服务器地址，无需修改。  
> 仅需修改 `WIFI_SSID`、`WIFI_PASSWORD`、`BEMFA_UID` 三项。

## 二、注册巴法云账号并获取私钥

### 2.1 注册

浏览器打开 **bemfa.com**，点击右上角"注册"，使用邮箱完成注册。

### 2.2 获取私钥 (UID)

1. 登录后进入"控制台" → "个人信息"
2. 复制 **"用户私钥 (UID)"** (32 位十六进制字符串，格式如 `382d6976a7f647bb856143e0b32eb9d3`)
3. 将此 UID 填入 `App_Net.h` 的 `BEMFA_UID` 宏

### 2.3 创建 TCP 设备主题

1. 进入"控制台" → "TCP 创客云"
2. 点击"新建主题"，输入主题名（如 `WPT001`）
3. 将此主题名填入 `App_Net.h` 的 `BEMFA_TOPIC` 宏

## 三、给单片机上电

### 3.1 启动过程

1. 用 USB 线给 STM32 开发板上电
2. 观察 OLED 屏幕启动过程:

   ```
   第 1 屏: "Wireless Charge"
            "WiFi Connecting"
            "Connecting..."
   ```
   
   约 20~30 秒后:
   
   ```
   第 2 屏: "WiFi Connected!"
            "TCP: OK"
            "Port: 8344"
   ```

   随后进入正常数据显示界面。

3. 如果 OLED 显示 `!!! WiFi Error !!!` 并带有错误码:

   | 错误码 | 含义 | 排查方向 |
   |:---:|:---|:---|
   | 1 | 模块无 AT 响应 | 检查 PA2/PA3 接线、供电 3.3V、波特率 |
   | 2 | CWMODE 失败 | 更换 ESP8266 固件或模块 |
   | 3 | WiFi 连不上 | 检查 SSID 拼写、密码、路由器 2.4G 频段 |
   | 4 | TCP 连不上 | 检查路由器能否访问外网 (ping 114.116.142.124) |
   | 5 | CIPMODE 失败 | 模块固件版本不兼容 |
   | 6 | CIPSEND 失败 | 重复尝试或检查模块 |

## 四、验证巴法云通信

### 4.1 确认设备在线

1. 打开巴法云控制台 → **"TCP 创客云"**
2. 在对应主题下，查看设备状态是否为 **"在线"**

### 4.2 查看遥测数据

单片机联网成功后，每 **2 秒** 自动上报一条数据。在巴法云控制台的消息记录中可看到：

```json
{"V":24.50,"I":1.23,"F":100000}
{"V":24.48,"I":1.25,"F":100000}
{"V":24.52,"I":1.21,"F":100000}
```

**字段说明**:

| 字段 | 含义 | 示例值 |
|:---:|:---|:---|
| `V` | 母线电压 (单位: 伏特 V) | `24.50` = 24.5V |
| `I` | 母线电流 (单位: 安培 A) | `1.23` = 1.23A |
| `F` | PWM 开关频率 (单位: Hz) | `100000` = 100kHz |

> 🎯 **判断标准**: 如果能连续收到 3 条以上数据且格式完整，说明 **STM32 → ESP8266 → 巴法云的上行链路工作正常**。

### 4.3 远程控制测试

#### 方式一：巴法云 APP (推荐)

1. 手机下载 "巴法云" APP (应用商店搜索 "Bemfa")
2. 登录后在对应主题下，输入指令并发送

#### 方式二：巴法云网页控制台

1. 打开 TCP 创客云 → 对应主题
2. 在消息下发框中输入指令，点击发送

#### 下发的指令与预期响应:

| 发送内容 | 预期单片机响应 |
|:---|:---|
| `CMD:ON` | OLED 显示 `CMD: Remote ON`，触发软启动扫频 150k→100kHz (~2.5s) |
| `CMD:OFF` | OLED 显示 `CMD: Remote OFF`，PWM 输出关闭，全桥安全关断 |

> 📌 **注意**:
> - 指令必须使用 **`CMD:ON`** / **`CMD:OFF`** 格式 (巴法云下发时会自动包裹在 cmd=2 协议信封中)
> - 扫频期间 (SS_SWEEP 状态) 暂停遥测上报，不影响扫频时序
> - 每次 `CMD:ON` 都会触发全新软启动 150k→100kHz 扫频
> - ESP8266 断线时，`CLOSED` 帧触发自动关断 PWM 并回到待联网界面

## 六、常见故障排查

### 6.1 设备显示离线 (连不上巴法云)

**排查步骤**:
1. **WiFi 外网**: ESP8266 连接的路由器必须能访问公网。在 PC 上 `ping 114.116.142.124` 确认可达。
2. **UID/Topic 未填或错误**: 检查 `App_Net.h` 中 `BEMFA_UID` 和 `BEMFA_TOPIC` 是否正确。
3. **路由器 DNS**: 如果路由器 DNS 不正常，`SERVER_IP` 已经用 IP 直连，不依赖 DNS。
4. **防火墙**: 部分企业网络防火墙封禁非标准端口 (8344)。尝试用手机热点测试。

### 6.2 能在线但收不到遥测数据

- 确认单片机已完成软启动 (处于 SS_DONE 或 SS_IDLE 状态)
- 扫频期间 (SS_SWEEP) 跳过遥测，等待 ~2.5s 扫频结束后恢复正常上报

### 6.3 指令下发没反应

- 确认发送的是 **`CMD:ON`** / **`CMD:OFF`** (大小写敏感)
- 确认设备处于在线状态
- 巴法云下发有 1Hz 限流，两次指令间隔至少 1 秒

### 6.4 ESP8266 频繁断连

- 供电不足是 **90% 断连问题的根因**。不要用 STM32 开发板上的 3.3V LDO 给 ESP8266 供电！
- 推荐方案: 独立 AMS1117-3.3 + 100μF 电解电容并联 0.1μF 陶瓷电容
- ESP8266 VCC 引脚与 GND 之间就近焊接 100μF 钽电容/电解电容滤除 WiFi 突发电流

### 6.5 ESP8266 掉电自动保护

- ESP8266 模块断开时，单片机收到 `CLOSED` 帧后**立即**关断 PWM 输出
- OLED 回到 "Press KEY0 WiFi" 界面
- 重新给 ESP8266 上电后，按 KEY0 重新联网即可恢复

### 6.6 多次联网后 ESP8266 卡死

- 固件启动流程包含**双重复位机制** (CH_PD 硬件复位 1000ms + AT+RST 软件复位)
- 每次调用 `ESP8266_Init()` 均执行此流程，确保透传模式下状态机完全清除
- 如果多次 KEY0 取消+重联后出现异常，断开 MCU 电源重新上电即可恢复

## 七、开发者扩展指南

| 扩展方向 | 实现位置 | 说明 |
|:---|:---|:---|
| 更换 WiFi | `App_Net.h` → `WIFI_SSID` / `WIFI_PASSWORD` | 直接修改宏值重新编译 |
| 更换巴法云账号 | `App_Net.h` → `BEMFA_UID` | 替换为自己的私钥 |
| 增加遥测字段 | `App_Net.c` → `App_Net_Task` 遥测 snprintf | 在 JSON msg 中追加字段 |
| 增加远程指令 | `App_Net.c` → `App_Net_Task` 指令解析区 | 在 strstr 分支中添加新指令 |
| 调整遥测频率 | `App_Net.c` → `last_telemetry >= 2000` | 巴法云限制最低 1Hz (1000ms)，建议 2000ms |
| 更换为域名连接 | `App_Net.h` → `SERVER_IP` 改为 `"tcp.bemfa.com"` | 需要 DNS 支持，每次连接多 1~3s |
