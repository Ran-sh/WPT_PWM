## 2. STM32 串口验证

### 2.1 硬件接线

| USB-TTL 模块 | STM32 引脚 |
|:---|:---|
| TXD | PA3 (USART2_RX) |
| RXD | PA2 (USART2_TX) |
| GND | GND |

> 不需要接 USB-TTL 的 3.3V，STM32 由自身供电。

### 2.2 验证步骤

1. Keil MDK 编译 `PWM/Project.uvprojx`，烧录到 STM32
2. 打开串口助手，配置 **115200 bps / 8N1**，选择对应 COM 口
3. 观察上电后 OLED 显示 `Wireless Charge` → `Press KEY0 WiFi`
4. **按下 KEY0**：OLED 显示 `HW Init...`，等待约 3 秒后显示 `WiFi: READY`
5. 串口助手应每隔 **2 秒** 收到一行 JSON：

```
{"V":12.50,"I":1.23,"F":100000}
```

6. 从串口助手**发送**以下字符串测试控制：

| 发送内容 | 预期结果 |
|:---|:---|
| `CMD:ON\n` | OLED 显示 `CMD: Remote ON`，逆变器开始扫频 |
| `CMD:OFF\n` | OLED 显示 `CMD: Remote OFF`，逆变器关断 |

> 注意：必须以 `\n` (换行符) 结尾，否则 STM32 的帧检测不会触发。

### 2.3 无串口模块时的简化验证

即使没有 USB-TTL 模块，也可以通过 OLED 和 LED 验证：

- **KEY0 单击后**：PB5 (Ready LED) 常亮 → 表示 `App_Net_Init()` 成功返回
- **PB3 (WiFi LED)**：常亮 → `s_WiFiConnected = 1` 生效
- **KEY0 再次单击**（SS_IDLE 状态）：逆变器软启动扫频正常执行

## 3. ESP8266 Arduino 固件烧录

### 3.1 Arduino IDE 环境配置

1. 下载安装 [Arduino IDE](https://www.arduino.cc/en/software) (1.8.x 或 2.x 均可)

2. 添加 ESP8266 开发板支持：

   - 文件 → 首选项 → 附加开发板管理器网址
   - 填入：`http://arduino.esp8266.com/stable/package_esp8266com_index.json`
   - 工具 → 开发板 → 开发板管理器
   - 搜索 `ESP8266` → 安装 `esp8266 by ESP8266 Community` (3.x 版本)

3. 安装 PubSubClient 库：

   - 工具 → 管理库
   - 搜索 `PubSubClient` → 安装 `PubSubClient by Nick O'Leary`

### 3.2 修改配置宏

打开 `ArduinoProject/ESP8266_MQTT_Firmware/ESP8266_MQTT_Firmware.ino`，修改以下宏：

```cpp
#define WIFI_SSID       "你的WiFi名称"
#define WIFI_PASSWORD   "你的WiFi密码"

#define MQTT_SERVER     "mqtt.heclouds.com"     // OneNET MQTT 地址
#define MQTT_PORT       6002

#define MQTT_CLIENT_ID  "WPT_PWM_001"
#define MQTT_USERNAME   "你的OneNET产品ID"
#define MQTT_PASSWORD   "你的OneNET鉴权信息"
```

> 如果暂时不接 OneNET，可以将 MQTT_SERVER 指向本地 PC 的 Mosquitto 或公共测试 MQTT broker（如 `test.mosquitto.org:1883`）进行调试。

### 3.3 烧录步骤

1. **接线**：USB-TTL 模块连接 ESP8266-01

| USB-TTL | ESP8266-01 |
|:---|:---|
| TXD | RXD |
| RXD | TXD |
| 3.3V | VCC, CH_PD/EN |
| GND | GND, GPIO0 |

> 关键：**GPIO0 必须接 GND** 才能进入烧录模式。烧录完成后断开 GPIO0-GND 并重新上电。

2. **Arduino IDE 设置**：

   - 工具 → 开发板 → **Generic ESP8266 Module**
   - Flash Size: `1M (no SPIFFS)`
   - Upload Speed: `115200`
   - CPU Frequency: `80 MHz`

3. 点击 **上传** (→) 按钮，等待编译和烧录完成

4. 烧录完成后：**断开 GPIO0-GND** → 重新上电 ESP8266

### 3.4 验证 ESP8266 是否正常工作

打开串口监视器 (工具 → 串口监视器，波特率 **115200**)，观察：

1. ESP8266 上电后连接 WiFi（板载蓝灯闪烁）
2. WiFi 连接成功后连接 MQTT
3. 从串口监视器**发送** `{"V":12.5,"I":1.2,"F":100000}` → 串口监视器无回显（数据已发布到 MQTT）
4. 在 MQTT 平台向订阅主题 `CMD` 发送 `ON` → 串口监视器应输出 `CMD:ON`

## 4. STM32 + ESP8266 联调

### 4.1 完整接线

```
STM32 PA2 (TX) ──── ESP8266 RXD
STM32 PA3 (RX) ──── ESP8266 TXD
STM32 GND      ──── ESP8266 GND
STM32 PB1      ──── ESP8266 CH_PD/EN (可选，通过 10kΩ 上拉到 3.3V)
```

> ESP8266 需要独立 3.3V LDO 供电 (≥500mA，如 AMS1117-3.3)，不可从 STM32 开发板取电。

### 4.2 联调步骤

1. 先给 ESP8266 上电，等待 WiFi + MQTT 连接完成 (~5s)
2. 再给 STM32 上电
3. STM32 按 KEY0 → `App_Net_Init()` 执行 CH_PD 低电平复位 ESP8266 → USART2 初始化
4. 之后 STM32 每 2s 自动发送 JSON，ESP8266 自动转发到 MQTT
5. MQTT 下发 `ON` → ESP8266 → STM32 收到 `CMD:ON` → 启动逆变器

### 4.3 故障排查

| 现象 | 可能原因 | 解决方法 |
|:---|:---|:---|
| STM32 无 JSON 输出 | `s_WiFiConnected=0` | 检查 KEY0 是否触发 `App_Net_Init()` |
| ESP8266 不连 WiFi | SSID/密码错误 | 检查宏定义，确认 WiFi 频段是 2.4GHz |
| ESP8266 连上 WiFi 但不连 MQTT | MQTT 参数错误 | 检查服务器地址和端口 |
| STM32 收不到 `CMD:ON` | 收发交叉接反 | 交换 TXD/RXD 再试 |
| ESP8266 烧录失败 | GPIO0 未拉低 | 检查 GPIO0 是否可靠接 GND |
| 透传模式下无法烧录 | 旧固件占用串口 | 先给 GPIO0 接 GND 再上电进入烧录模式 |
