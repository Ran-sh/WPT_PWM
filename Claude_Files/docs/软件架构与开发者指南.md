## 1. 系统概述

### 1.1 设计目标

本系统是一套基于 STM32F103C8T6 的无线充电全桥谐振电源控制方案。核心目标是将功率级全桥 PWM 控制、人机交互和系统监控整合为一个高内聚、低耦合的嵌入式软件系统。纯本地按键控制，无需网络连接。

### 1.2 功能清单

| 编号 | 功能模块 | 详细描述 |
|:---:|:---|:---|
| F1 | **全桥 PWM 驱动** | TIM1 四通道互补输出 (CH1/CH1N/CH2/CH2N), 占空比锁定 50%, 频率 95kHz~150kHz PFM, 1000ns 死区 |
| F2 | **非阻塞软启动扫频** | 150kHz → 100kHz, 200Hz/步, 10ms/步, 共 250 步 ≈ 2.5s; SS_IDLE/SWEEP/DONE/FAULT 四态状态机 |
| F3 | **防偏磁保护** | 周期 ticks 强制偶数, 正负半周对称; 影子寄存器 UDIS/UG 原子更新 |
| F4 | **ADC 采集 + 滤波** | ADC1+DMA 双通道循环扫描, 16 样本 O(1) 滑动平均, ADC_Filter_Task 2ms 独立滤波, 32ms 响应 |
| F5 | **OLED 双页显示** | SSD1306 128×64 模拟 I2C, Page0 控制面板 (按键可操作) + Page1 锁屏监控 (只读) |
| F6 | **按键交互** | PB12/PB13 双键, 七态 FSM 单击/双击识别, 10ms 去抖, 200ms 双击窗口 |

## 2. 核心模块详解

### 2.1 SysTimer 时基总管

#### 2.1.1 设计动机

传统裸机开发采用 `delay_ms()` 阻塞延时或 `Flag_Task_xxx` 中断标志位。前者阻塞 CPU, 后者导致逻辑分散、模块耦合。SysTimer 通过全局毫秒时间戳和"时间戳差值法"同时解决这两个问题。

#### 2.1.2 核心实现

```c
/* System/SysTimer.c */
static volatile uint32_t s_SysTick = 0;  // ISR写入, 主循环读取, 必须volatile

void SysTimer_Init(void)    { SysTick_Config(SystemCoreClock / 1000); }
void SysTimer_IncTick(void) { s_SysTick++; }
uint32_t SysTimer_GetTick(void) { return s_SysTick; }
```

#### 2.1.3 时间戳差值法

```c
void Some_Task(void) {
    static uint32_t last = 0;
    if (SysTimer_GetTick() - last >= PERIOD_MS) {
        last = SysTimer_GetTick();
        // 周期业务
    }
}
```

利用 uint32_t 无符号减法自动处理 49.7 天溢出回绕。

#### 2.1.4 重构前后对比

| 项目 | 重构前 | 重构后 |
|:---|:---|:---|
| 时基来源 | `g_MsTick` 在 `stm32f10x_it.c` 中定义 | `s_SysTick` 在 `SysTimer.c` 中 static 封装 |
| 任务调度 | `Flag_Task_Key1/OLED/LED` 中断标志位 | `static uint32_t last` + `GetTick()` 时间戳差值 |
| SysTick_Handler | 含 3 个 software timer + KEY_Scan_All | 1 行 `SysTimer_IncTick()` |
| 模块耦合 | 全局 `extern` 变量跨模块裸露 | `static` 封装 + 公开只读接口 |

### 2.2 PWM 驱动、防偏磁与软启动

#### 2.2.1 全桥拓扑与引脚映射

TIM1 高级定时器, `GPIO_PartialRemap_TIM1` 部分重映射, 四通道互补输出:

| 信号 | 引脚 | 栅极驱动 | MOS 管 |
|:---|:---|:---|:---|
| CH1 (PWM1) | PA8 | IR2103S HIN (高有效) | 上半桥左臂上管 Q1 |
| CH1N | PA7 | IR2103S LIN (低有效) | 下半桥左臂下管 Q2 |
| CH2 (PWM2) | PA9 | IR2103S HIN (高有效) | 上半桥右臂上管 Q3 |
| CH2N | PB0 | IR2103S LIN (低有效) | 下半桥右臂下管 Q4 |

CH1=PWM1 模式, CH2=PWM2 模式, 相位差 180° 对角线导通。Q1+Q4 通 → 电流正向; Q2+Q3 通 → 电流反向。

#### 2.2.2 死区配置

```c
#define DEADTIME_NS  1000   // PWM.h — 修改此值调整死区
// TDTS = 13.889ns @ 72MHz CKD_DIV1
// DEADTIME_REG_VAL = ((DEADTIME_NS) * 72 + 500) / 1000
// 编译期断言: typedef char __deadtime_linear_check[(DEADTIME_REG_VAL <= 127) ? 1 : -1];
```

代入 DEADTIME_NS=1000 → DTG=72, 死区 ≈ 1000ns。BDTR 线性段断言 DTG ≤ 127, 超过则编译报错。

**OIS 空闲态配置**: MOE=0 时 CH1/CH2→低(上管关), CH1N/CH2N→高(下管关), 4 个 MOSFET 全部可靠关断。

#### 2.2.3 防偏磁 — 周期强制偶数

```c
ticks = 72000000 / freq_Hz;
if (ticks % 2 != 0) ticks += 1;   // 强制偶数 — 正负半周对称
arr = ticks - 1;
ccr = ticks / 2;                   // 50% 整除无余数
```

#### 2.2.4 影子寄存器原子更新 (UDIS/UG)

```c
TIM1->CR1 |= TIM_CR1_UDIS;           // 暂停影子寄存器传输
TIM_SetAutoreload(TIM1, arr);
TIM_SetCompare1(TIM1, ccr);
TIM_SetCompare2(TIM1, ccr);
TIM1->EGR |= TIM_EGR_UG;            // 软件触发, 原子加载全部影子寄存器
TIM1->CR1 &= ~TIM_CR1_UDIS;         // 恢复硬件更新
```

防止 Update Event 在 ARR 和 CCR 写入之间触发, 导致新周期配旧占空比 → 偏磁 → 炸管。

#### 2.2.5 非阻塞软启动状态机

```
SS_IDLE ──Trigger──→ SS_SWEEP (150kHz) ──250步→ SS_DONE (100kHz)
   ↑                      │                       │
   │      ┌───────────────┘                       │
   │      ▼                                       │
   └──Stop(KEY0/KEY1) ←────────── Stop(KEY0) ─────┘
   │
   │  Fault(过流) → SS_FAULT (锁存, KEY0/KEY1复位)
   └────────────────────────────────────────────┘
```

参数: 起始 150kHz, 目标 100kHz, 步长 200Hz, 节拍 10ms, 250 步 ≈ 2.5s。

```c
void Inverter_SoftStart_Trigger(void);   // SS_IDLE → SS_SWEEP, 开MOE
void Inverter_SoftStart_Task(void);      // 主循环调用, 10ms时间戳步进
void Inverter_SoftStart_Stop(void);      // 关MOE → SS_IDLE
void Inverter_SoftStart_Fault(void);     // 紧急关断 → SS_FAULT锁存
```

#### 2.2.6 公开接口

| 函数 | 说明 |
|:---|:---|
| `PWM_Init()` | 初始化 TIM1 全桥, 150kHz 默认, MOE 关断 |
| `PWM_SetFrequency(Hz)` | 动态设置频率 (95k~150k 硬限幅) |
| `PWM_GetFrequency()` | 从 TIM1->ARR 反算当前频率 |
| `PWM_Enable()` | 先开计数器, 再开 MOE |
| `PWM_Disable()` | 先关 MOE, 再停计数器 |

**规则**: UI 和其他模块禁止直接操作 `TIM_Cmd`/`TIM_CtrlPWMOutputs`/`TIM1->ARR`, 必须通过以上接口。

### 2.3 ADC 采集与滑动滤波

#### 2.3.1 硬件配置

ADC1 + DMA1_Channel1 双通道循环扫描:
- PA0 = 电流 (CC6920-10A 霍尔, VREF=3.30V, I_SENSITIVITY=0.132V/A, I_OFFSET=1.65V)
- PA1 = 电压 (20:1 分压)

ADC 时钟 = 72MHz/6 = 12MHz。DMA 循环模式, 后台持续刷新 `ADC_ConvertedValue[2]`。

#### 2.3.2 16 样本 O(1) 滑动平均

100kHz 强磁场下 DMA 瞬时值噪声严重。使用 O(1) 运行累加器避免每帧重复求和:

```c
#define ADC_FILTER_WINDOW  16

// 电压通道:
uint16_t old_v = s_vbuf[s_vidx];        // 保存最旧值
s_vbuf[s_vidx] = ADC_ConvertedValue[1]; // 覆盖新值
s_vaccum += s_vbuf[s_vidx];             // 累加新值
if (s_vfilled >= ADC_FILTER_WINDOW)
    s_vaccum -= old_v;                  // 减去真正的最旧值 (O(1) 替代 O(N) 求和)
s_vidx = (s_vidx + 1) % ADC_FILTER_WINDOW;
```

#### 2.3.3 ADC_Filter_Task — 独立滤波任务

```c
void ADC_Filter_Task(void) {
    static uint32_t last = 0;
    if (SysTimer_GetTick() - last < 2) return;  // 2ms 节拍
    last = SysTimer_GetTick();
    // 推入样本 → 更新滑动平均 → 存入 s_voltage / s_current
}
float Get_Real_Voltage(void) { return s_voltage; }  // O(1) 直接返回
```

响应延迟 32ms (16×2ms), vs 旧方案 3.2s (16×200ms)。

#### 2.3.4 ADC 校准时序

`ADC_Cmd(ENABLE)` 后须等待 t_STAB ≥ 2 ADC 周期才能校准, 否则基准漂移。12MHz ADC 时钟下 2 周期 = 167ns, 代码中等 ~2μs 足够。

### 2.4 KEY 按键驱动

#### 2.4.1 七态状态机

```
IDLE ──电平=低──→ DEBOUNCE ──仍低──→ PRESSED
                                          │
  ←── 投递单击=1 ← IDLE ← 超时200ms ← WAIT_DOUBLE ← 电平变高 ← WAIT_RELEASE
                                          │ ↑
  ←── 投递双击=2 ← IDLE ← WAIT_DOUBLE_REL ←┘ 再次按下又释放
```

#### 2.4.2 按键功能

| 键 | 引脚 | 单击 | 双击 |
|:---|:---|:---|:---|
| KEY0 | PB12 (IPU) | SS_IDLE→Trigger / SS_DONE→Stop / SS_FAULT→复位 | 切页 |
| KEY1 | PB13 (IPU) | SS_SWEEP→Stop / SS_DONE→+1kHz / SS_FAULT→复位 | — |

`KEY_Task()`: 10ms 时间戳差值调度。`KEY_Get_Event()`: 阅后即焚 (0=无, 1=单击, 2=双击)。

### 2.5 OLED 显示驱动

SSD1306 128×64, 软件模拟 I2C (PA11=SCL, PA12=SDA, 开漏输出), 从机地址 0x78。

- 字体: 8×16 ASCII (`OLED_Font.h`), 4 行 × 16 字符
- `OLED_Clear()` 耗时 ~100ms (1024 字节 I2C), 仅在状态迁移/切页时调用
- 日常 200ms 刷新: 16 字符全宽行覆盖, 不调用清屏
- `OLED_ShowFloatNum`: 带四舍五入补偿, 正数留空格防重影

支持: ShowChar, ShowString, ShowNum, ShowSignedNum, ShowHexNum, ShowBinNum, ShowFloatNum。

### 2.6 UI 用户界面

双页设计, 200ms 刷新周期。

**Page 0 — 控制面板** (可操作):
- SS_IDLE: "Press KEY0 start"
- SS_SWEEP: 实时频率 + 进度条 `[####      ]`
- SS_DONE: 频率/电压/电流 + "K0:Stop K1:+1k"
- SS_FAULT: "!!! FAULT !!! Over Current / K0/K1: Reset"

**Page 1 — 锁屏监控** (只读):
- 频率/电压/电流显示, 按键操作被屏蔽
- 仅 KEY0 双击可切回 Page 0

KEY0 双击切页。KEY0 单击直接触发软启动 (无需联网步骤)。

### 2.7 LED 状态指示

JTAG 禁用, SWD (PA13/PA14) 保留, 释放 PB3/PB4 为 GPIO。

| LED | 引脚 | 有效电平 | 行为 |
|:---|:---|:---|:---|
| 心跳 | PC13 | 低 | 500ms 翻转, `LED_Task()` |
| 状态 | PB3 | 高 | 保持熄灭 (无 WiFi) |
| PWM | PB4 | 高 | 快闪=SS_SWEEP, 慢闪=SS_DONE, 灭=其他 |
| Ready | PB5 | 高 | Page0 + (IDLE/DONE) → 亮; FAULT → 灭 |

上电自检: PB3/PB4/PB5 全亮 ~1s 后全灭。`LED_Status_Task()` 驱动 PB3/PB4 闪烁, 由 `UI_Task()` 内调用。

### 3.1 主循环调度模型

     ┌──────────────────────────────────────────────────────┐

     └──────────────────────────────────────────────────────┘
                          │
      ┌──────┬──────┬──────┼──────┬──────┐

   ┌──────┐┌──────┐┌──────┐┌──────┐┌──────┐

   │      ││2ms   ││      ││10ms  ││      │
   └──┬───┘└──┬───┘└──┬───┘└──┬───┘└──┬───┘

### 3.2 按键 → PWM 控制流

```
KEY0单击 → KEY_Task(10ms) → KEY_Get_Event(0)=1
  → UI_HandleKeys → Inverter_SoftStart_Trigger
    → PWM_Enable (开MOE) → PWM_SetFrequency(150k)
      → Inverter_SoftStart_Task 每10ms降频200Hz → 100kHz → SS_DONE

KEY1单击(SS_DONE) → PWM_GetFrequency → +1000
  → PWM_SetFrequency (100k~150k封顶不绕回)
```

### 3.3 ADC 数据流

```
PA0(电流)/PA1(电压) → ADC1 双通道扫描 → DMA1_Channel1 循环
  → ADC_ConvertedValue[2] (ISR级别自动刷新)
    → ADC_Filter_Task (2ms) 推入环形缓冲
      → O(1)运行累加器 → s_voltage / s_current
        → Get_Real_Voltage/Current (O(1)返回)
          → UI_Task (200ms) OLED 显示
```
