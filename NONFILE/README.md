# NONFILE 归档区

本目录只保存不参与当前 V5.1.3 构建、部署和运行，但仍需要追溯的历史资料。归档不是删除，也不得从这里直接引用生产代码。

## 目录用途

| 目录 | 内容 |
|:---|:---|
| `history/reports/` | 已完成任务的检查报告 |
| `history/stm32-designs/` | 旧版 STM32 设计、实施计划和验证记录 |
| `history/miniprogram-designs/` | 旧版小程序设计稿 |
| `legacy-docs/` | 已合并到根目录总手册的重复文档 |
| `legacy-diagrams/` | 当前不维护的旧图纸和生成脚本 |

## 强制规则

- 当前代码不得 `include`、`require`、导入或执行本目录文件。
- 新增历史资料时先放入对应子目录，禁止散落到项目根目录。
- 需要恢复旧资料时，先复制到新的工作分支并升级到当前接口，禁止直接覆盖现行文件。
- 当前有效的说明只认根目录 `WPT无线充电系统-从零搭建完整操作手册.md`。
- 当前有效的架构约束只认根目录 `AGENTS.md` 和 `.agents/skills/embedded-architect/SKILL.md`。
- 本目录可以保留旧版本号；这些版本号表示历史内容，不参与全项目当前版本检查。
