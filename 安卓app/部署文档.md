# 桥接服务器部署文档

## 方式一：Railway.app（推荐，免费）

Railway 提供免费额度（$5/月），自动 HTTPS，部署后获得 `xxx.up.railway.app` 域名。

### 步骤

**1. 注册**

打开 [railway.app](https://railway.app) → Sign in with GitHub → 授权

**2. 部署**

```
1. 点击 New Project → Deploy from GitHub
2. 选择 WPT_PWM 仓库（或新建一个仓库只放 server/ 目录）
3. Railway 自动检测 Node.js 并部署
```

**3. 配置 Root Directory**

部署后在 Settings → Root Directory 填入：`安卓app/server`

**4. 获取域名**

Deployments → 点击生成的域名，格式为 `xxx.up.railway.app`

**5. 修改小程序代码**

打开 `pages/index/index.js`，将 BRIDGE 改为：

```js
const BRIDGE = 'https://xxx.up.railway.app';
```

### 需要推送到 GitHub 的文件

确保以下文件在仓库中：
```
安卓app/server/
├── package.json
└── bridge.mjs
```

推送命令：
```bash
cd D:\Claude Code Project\WPT_PWM_V4.0_ONENET_TFT
git add 安卓app/server/
git commit -m "feat: add bridge server for Mini Program"
git push
```

## 方式二：ngrok 临时测试（最快）

不需要部署，适合开发调试。

### 步骤

**1. 下载 ngrok**

[ngrok.com/download](https://ngrok.com/download) → 注册账号 → 获取 authtoken

**2. 启动**

```bash
ngrok config add-authtoken <你的token>
ngrok http 3000
```

输出：
```
Forwarding  https://xxxx.ngrok-free.app → http://localhost:3000
```

**3. 修改小程序**

```js
const BRIDGE = 'https://xxxx.ngrok-free.app';
```

> ngrok 免费版每次重启 URL 会变，PC 关机就断。适合测试，不适合验收。

## 方式三：自有云服务器

如果你有阿里云/腾讯云 VPS：

**1. 上传代码**

```bash
scp -r 安卓app/server/ root@你的服务器IP:/opt/wpt-bridge/
```

**2. 安装依赖 + 启动**

```bash
ssh root@你的服务器IP
cd /opt/wpt-bridge
npm install
node bridge.mjs &
```

**3. 配置 Nginx 反向代理 + SSL**

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    location / {
        proxy_pass http://127.0.0.1:3000;
    }
}
```

**4. 小程序后台配置**

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 开发管理 → 服务器域名

| 类型 | 域名 |
|:---|:---|
| request 合法域名 | `https://your-domain.com` |

**5. 修改小程序**

```js
const BRIDGE = 'https://your-domain.com';
```

## 验证部署

```bash
curl https://你的域名/data
```

应返回：
```json
{"voltage":12.5,"current":1.23,"frequency":100000,"updated":1700000000000}
```
