# WPT 微信小程序 — 操作手册

**版本**: V3.0.0 | **日期**: 2026-06-17

---

## 1. 准备工作

### 1.1 注册微信小程序

1. 打开 [微信公众平台](https://mp.weixin.qq.com/) → 点击"立即注册" → 选择"小程序"
2. 填写邮箱、密码，激活账号
3. 完成主体信息登记（个人或企业）
4. 进入后台 → 开发 → 开发管理 → 开发设置 → 复制 **AppID**

### 1.2 安装微信开发者工具

下载安装：[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

---

## 2. 导入项目

1. 打开微信开发者工具 → 点击"+" → 导入项目
2. 目录选择：`D:\Claude Code Project\WPT_PWM_ONENET_V3.0\安卓app`
3. AppID：粘贴你的 AppID
4. 项目名称：`wpt-monitor`
5. 点击"确定"

---

## 3. 修改配置

### 3.1 AppID

打开 `project.config.json`，将 `appid` 改为你的 AppID：

```json
"appid": "wx1234567890abcdef"
```

### 3.2 桥接服务器地址

打开 `pages/index/index.js`，将 `BRIDGE` 改为 ngrok 公网地址：

```javascript
const BRIDGE = 'https://xxx-xxx-xxx.ngrok-free.dev';
```

> 启动桥接服务器 + ngrok 后，脚本会自动输出此地址。详见 `Claude_Files/docs/桥接服务器部署指南.md`。

### 3.3 设置不校验合法域名（仅开发阶段）

开发工具 → 右上角"详情" → 本地设置 → 勾选**"不校验合法域名"**

> 上线前需在小程序后台 → 开发管理 → 服务器域名 → 添加桥接服务器域名为合法 HTTPS 域名。

1. 启动桥接服务器 + ngrok（`start_bridge.ps1`）
2. 确保 ESP8266 已上电并连上 EMQX

## 5. 数据说明

| 字段 | 来源 | 说明 |
|:---|:---|:---|
| 电压 | STM32 ADC → ESP8266 → EMQX → 桥接 → 小程序 | 20:1 分压 |
| 电流 | STM32 ADC → ESP8266 → EMQX → 桥接 → 小程序 | CC6920-10A 霍尔传感器 |
| 频率 | STM32 PWM → ESP8266 → EMQX → 桥接 → 小程序 | kHz 整数显示，与 OLED 一致 |
| 状态 | 小程序推断 | IDLE=待机 / SWEEP=扫频中 / DONE=运行中 / FAULT=故障 |

---

## 6. 控制操作

| 操作 | 条件 | 发送指令 | 效果 |
|:---|:---|:---|:---|
| **START** | IDLE 状态 | `CMD:ON` | 触发软启动扫频 150k→100k |
| **STOP** | SWEEP/DONE 状态 | `CMD:OFF` | 关断逆变器，回 IDLE |
| **频率滑块** | DONE 状态 | `CMD:SETFREQ:<Hz>` | 直接设置频率 95k~150kHz |

> 拖动滑块松手后立即发送，Toast 提示当前设定值。频率仅在"运行中"(DONE)状态有效。

---

## 7. 故障排查

| 现象 | 原因 | 解决 |
|:---|:---|:---|
| 小程序白屏 | 编译错误 | 查看控制台红色报错 |
| 显示"--"，connected:false | 桥接服务器未启动 | 启动桥接 + ngrok |
| 数据不刷新 | HTTP 请求失败 | 检查手机网络 + ngrok 是否在线 |
| 滑块不生效 | 设备未处于 DONE 状态 | 确保 START 后扫频完成 |
| 滑块灰显不可拖动 | isOn=false | 启动设备后再调频 |
| 真机扫码无显示 | ngrok 隧道挂了 | 重启 ngrok，更新 BRIDGE 地址 |

---

## 8. 数据流架构

```
微信小程序 ──HTTPS── ngrok ── 桥接服务器 ──MQTT── EMQX ── ESP8266 ──Serial── STM32
   (真机)      (公网)       (localhost:3000)       (1883)              (115200)

数据上行: STM32 → ESP8266 → EMQX → 桥接 → 缓存 → 小程序 GET /data (2s 轮询)
指令下行: 小程序 POST /cmd → 桥接 → EMQX → ESP8266 → STM32
                               (wpt/20260001/cmd)    (CMD:ON / CMD:OFF / CMD:SETFREQ:100000)
```

> 详细部署说明见 `Claude_Files/docs/桥接服务器部署指南.md`
