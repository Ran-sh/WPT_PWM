# WPT 微信小程序操作手册

**版本**: V5.1.2 | **更新**: 2026-07-26

## 1. 导入与配置

1. 在微信开发者工具中导入 `安卓app` 目录。
2. 在 `project.config.json` 中填入小程序 AppID。
3. 开发阶段可在“本地设置”中勾选“不校验合法域名”；正式发布前，将 `https://iot-api.heclouds.com` 加入 request 合法域名。
4. 打开小程序“设置”，填写 OneNET 的 Product ID、Device Name 和 Token，然后点击保存。

Token 只保存在微信本地存储中，不应写入代码或提交到 Git。

## 2. 页面功能

- **首页**：显示电压、电流、实际频率、运行状态和连接状态。
- **实时监测**：显示传感器状态和最近趋势，返回页面后会自动恢复轮询。
- **设备控制**：启停设备，选择频率档位并设定运行频率。
- **历史查询**：查看最近24小时数据，并导出 CSV。
- **报警**：查看越界记录；异常状态持续时不会反复刷屏。
- **设置**：管理 OneNET 配置、界面名称、报警振动和本地数据。

## 3. 启停与频率设置

| 操作 | 结果 |
|:---|:---|
| 打开启停开关 | 下发 `Switch=true`，STM32按保存的启动档位扫频 |
| 关闭启停开关 | 下发 `Switch=false`，立即停止 PWM |
| 选择20–99.9k档 | 可设20.0–99.9kHz，步进0.1kHz |
| 选择100–200k档 | 可设100–200kHz，步进1kHz |
| 点击“确认设置” | 下发 `SetFreq`，固件平滑过渡到目标频率 |

小程序只在设备已运行时允许确认频率。设备离线时不会把 OneNET 的旧缓存值当成实时数据。

## 4. 数据链路

```text
微信小程序 ←HTTPS→ OneNET ←MQTT→ ESP8266 ←USART2→ STM32
```

小程序默认直连 OneNET HTTP API，不依赖 ngrok 或本地桥接服务器。`server` 目录的桥接程序仅用于独立调试和第三方集成。

## 5. 故障排查

| 现象 | 处理 |
|:---|:---|
| 显示“未配置” | 补齐 Product ID、Device Name 和 Token |
| 返回401 | 重新生成 Token，并检查有效期 |
| 显示离线 | 确认 ESP8266 已联网且 OneNET 设备状态在线 |
| 频率下发失败 | 确认设备正在运行，频率在20–200kHz内 |
| 真机请求被拦截 | 在小程序后台配置 OneNET HTTPS 合法域名 |
| 图表暂无数据 | 等待在线数据按分钟写入本地历史 |
